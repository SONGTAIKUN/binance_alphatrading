# P28 稳定经济 family ensemble 报告

## 结论

- 最终结论：**不覆盖 P15c；保留为研究结果**。
- P28e nested gross/net6/net8/Sharpe/MaxDD：15.08% / 9.42% / 7.59% / 0.800 / -8.89%。
- P15c 对照 gross/net6/net8/Sharpe/MaxDD：15.08% / 9.42% / 7.59% / 0.800 / -8.89%。
- 固定变体中净收益最高的是 P15c，但只有 P28e 是在 validation 内选择变体后拼接 test 的最终 selector 结果。
- P28e fallback 到 P15c 的 fold 比例为 100.0%；因此 P28e 实质上就是 P15c 的数值等价重放。
- 32/32 folds 通过 chronology / label closure 审计。

## P28a：选择过拟合审计

- 240 个名义公式的有效独立维度只有 3.1（1.3%）。
- PBO 为 62.0%；train winner 在另一半样本中的中位排名分位为 45.0%。
- P27 validation fitness 与同公式 test IC 的平均 rank correlation 为 0.173。
- 这部分是 post-hoc 诊断，不参与任何 P28 fold 的选择。

## 严格性与限制

- family member selection 只读 train；validation factor IC 只用在 train_end 前完整闭合的 168h label。
- variant/weight/fallback 只读 train、closed-label validation 和已经结束的历史 test folds；当前 test 完全不参与选择。
- 交易 validation 只使用在 train_end 前闭合的 72h return；test 交易全部在 test_end 前闭合。
- P28 family 假设是在观察 P27 后提出，存在研究序列层面的 meta-overfitting；即使 nested OOS 好，也仍需要未来 untouched sample。
