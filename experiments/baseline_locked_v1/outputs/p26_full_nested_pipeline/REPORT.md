# P26-full 完整 Nested Walk-forward 报告

## 协议

- Alpha residual model：`alpha_residual_v2_no_sector_ols720`；所有 residual-dependent features 已重建。
- Portfolio risk model：`portfolio_risk_v1_p15c`；BTC/ETH/market beta 与原 P15c 保持一致。
- 每个 outer fold 内：前半训练窗选 P4 参数并计算新版 terminal/path label IC；后半验证窗选 AlphaGPT 公式、候选权重和 P15c cluster 参数；只在下一段 test 交易。
- 公式语法和候选集合是预先固定的，不由 test 数据生成。

## Review 结论

- 结论：**不升级；P15c 继续作为正式 baseline，P26-full 保留为研究候选**。
- P26-full 的尾部 fold 有改善，但总体 gross、8bps net、Sharpe、MaxDD 和 positive-fold rate 没有同时胜过 P15c。
- 最差 5 个 fold 合计：P26-full -7.45%，P15c -10.69%；P26-full 更好。
- P26-full 在 53.1% 的 fold 胜过 P15c，但自身 positive-fold rate 从 62.5% 降到 56.2%。
- 换手只下降 1.1%；成本盈亏平衡约从 P15c 16.72bps 降到 P26-full 15.84bps。
- AlphaGPT hard-accept 率为 93.8%，选中了 27 个不同公式；P4 也选中了 26 个不同参数组。选择器偏活跃，跨 fold 参数稳定性不足。
- 最大相对失效发生在 2023Q4；P26-full gross 约 -2.37%，而 P15c 约 +4.50%。这说明新 residual/label 对后续 regime 有增量，但早期外推仍不稳定。

## 核心结果

- P26-full 6bps net：8.51%；P15c：9.42%。
- P26-full gross：14.06%；P15c：15.08%。
- P26-full Sharpe：0.784；P15c：0.800。
- P26-full MaxDD：-9.10%；P15c：-8.89%。
- 8bps net：P26-full 6.72%；P15c 7.59%。
- AlphaGPT fallback 到纯 P4：6.2%；P15c cluster sizing fallback：6.2%。
